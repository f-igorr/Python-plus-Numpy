учебный проект.
описание: проект состоит из модели управления запасами торговой точки (либо распределительного склада) и обучаемого агента.
цель: обучение агента поддержанию оптимального уровня складских запасов.
мозг агента - небольшая нейросеть.
обучение с помощью генетического алгоритма.

проект создан также для последующей демонстрации возможности ускорения выполнения программы с помощью Ctypes, Cython, Numba.
