# Система управления запасами торговой точки / склада

**Краткое описание:** Данный учебный проект представляет собой систему для оптимизации складских запасов в розничной точке или распределительном складе с использованием принципов машинного обучения.

## Основная идея
Цель проекта — научить автономного агента поддерживать оптимальный уровень товарных запасов, минимизируя издержки, связанные как с дефицитом (out-of-stock), так и с переизбытком товаров.

## Техническая реализация
Проект состоит из двух ключевых компонентов:
*   **Модель управления запасами:** Симуляционная модель торговой точки или склада.
*   **Обучаемый агент:** Интеллектуальная сущность, которая принимает решения о закупках и пополнении запасов.

### Методология обучения
- **"Мозг" агента:** Реализован на основе небольшой нейронной сети (Neural Network).
- **Алгоритм обучения:** Используется Генетический алгоритм (Genetic Algorithm) для поиска оптимальной стратегии управления.

## Оптимизация производительности
В данном проекте для оптимизации производительности используется только Numpy, оставляя возможность в следующих частях проекта использовать
дополнительные инструменты для повышения вычислительной эффективности:
*   `Ctypes`
*   `Cython`
*   `Numba`
